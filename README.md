# AU Suburb Shortlist

Mobile-first investment suburb screen (growth · yield · crime-filtered) with one-tap jumps to Domain and realestate.com.au.

**Live:** https://tburfordopti.github.io/au-suburb-shortlist/

## Filters already baked in
- Budget ≤ ~$500k (Kalbarri stretch $550k)
- Houses + units
- High-crime suburbs removed

## Use
Open the Pages URL on your phone, filter/sort, tap **Domain** or **realestate** for live listings.

## Local
```bash
python3 -m http.server 8080
```

## Disclaimer
Not financial advice. Yields are gross. Crime badges are relative to state/metro baselines.
